# Balloonのガイド

青空文庫形式のテキスト編集と校正を支援するWebエディタです。

## バグ報告・要望

GitHubのIssueにて、バグ報告や要望を受け付けています。お気軽にご連絡ください。

[Issuesを開く](https://github.com/furisake/balloon/issues)

## コントリビューション

Balloon Editorはオープンソースプロジェクトであり、誰でもコントリビューションできます。バグの報告や新機能の提案、コードの改善など、ぜひ参加してください。

[GitHubリポジトリを見る](https://github.com/furisake/balloon)
